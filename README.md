# Casious Foundation — Website Proposals

Three interactive prototypes demonstrating different package tiers for your NGO client.

## How to View

1. Open `index.html` in any web browser (double-click it)
2. Click any tier card to explore that prototype
3. All prototypes work offline — no server needed

**Optional local server** (if links behave oddly):
```powershell
cd "C:\Users\Casious Clay\Desktop\NGO"
python -m http.server 8080
```
Then visit: http://localhost:8080

## Tier Differences (Demo These to Client)

### Tier 1 — Starter
- Clean template design (blue theme)
- 6 core pages
- External donation links (PayPal/bank)
- Basic contact form
- Mobile responsive

### Tier 2 — Professional
- Custom green-branded design
- Embedded donation form with amount picker
- Blog / news section
- Impact statistics page
- Testimonials & newsletter signup
- CMS-ready structure

### Tier 3 — Advanced
- Premium purple-branded platform
- **English + Kiswahili** language switcher
- **Live animated impact dashboard**
- **Volunteer application portal** (multi-step form)
- **Events calendar** with registration
- **Annual report** download section
- Full payment gateway (Stripe, PayPal, Mobile Money)
- Partner logos & multiple office locations
